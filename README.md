Descripción del proyecto

TransporteRD es una aplicación web diseñada para ayudar a los usuarios a calcular tarifas estimadas de transporte entre diferentes ciudades de la República Dominicana. Su objetivo es ofrecer una referencia rápida y sencilla del costo del pasaje, facilitando la planificación de los viajes.

La aplicación permite seleccionar ciudades de origen y destino, indicar la cantidad de pasajeros y consultar el costo estimado del trayecto. Las tarifas son orientativas y pueden variar según el servicio de transporte.

Tecnologías utilizadas

React.js: para crear la interfaz de usuario.
JavaScript: para la lógica y los cálculos de la aplicación.
HTML5: para la estructura de la página.
CSS3: para los estilos y el diseño adaptable.
Vite: para el desarrollo y la construcción del proyecto.
Git y GitHub: para el control de versiones y el alojamiento del código fuente.

¿Qué aprendimos?

Con este proyecto reforzamos nuestros conocimientos sobre el desarrollo de aplicaciones web, la creación de componentes con React, el manejo de estados, la validación de datos y la implementación de cálculos mediante JavaScript.

También practicamos el trabajo en equipo, la organización de archivos de un proyecto, el uso de GitHub para compartir código y la preparación de una aplicación para su publicación en internet.

Objetivo del proyecto

Desarrollar una herramienta sencilla, útil y accesible que permita consultar tarifas estimadas de transporte entre ciudades dominicanas, aplicando los conocimientos adquiridos en la asignatura Lenguaje de Programación III.
